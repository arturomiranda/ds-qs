# Tabla: 002: Estados Financieros

Esta tabla almacena las configuraciones de los diferentes reportes financieros del sistema (Balance General, Estado de Resultados, etc.).

## 📄 Información General
- **ID de Tabla:** `002_EFI`
- **Tipo:** Maestro
- **Reside en:** Disco
- **Longitud del registro:** 113
- **Número de campos:** 4
- **Número de índices:** 5
- **Descripción:** Configuración de estructuras de estados financieros.

## 🛠️ Estructura de Campos

| Identificador | Nombre | Tipo | Longitud | Tipo de enlace |
| :--- | :--- | :--- | :--- | :--- |
| `ID` | Código | Numérico | 3 | |
| `NAME` | Titulo reporte | Alfa 256 | 100 | |
| `TIP` | Tipo | Alfa 256 | 1 | |
| `JS_CONF` | Configuracion de Col. | Objeto Texto | 8 | |

## 🔍 Índices

| Identificador | Nombre | Tipo de indice |
| :--- | :--- | :--- |
| `ID` | Código | Clave única |
| `NAME` | Alfabético | Acepta repetidas |
| `WORDS` | Palabras | Palabras |
| `PARTS` | Trozos de palabras | Trozos de palabras |
| `TIP` | Tipo | Acepta repetidas |

## 📝 Notas
- El campo `JS_CONF` almacena una estructura JSON con la configuración de las columnas y fórmulas del reporte.
- El tipo (`TIP`) define la categoría del estado financiero.
