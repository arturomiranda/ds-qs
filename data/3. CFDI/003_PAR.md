# Tabla: 003: Participantes

Esta tabla registra las entidades que participan en un CFDI y el rol que desempeñan (Emisor, Receptor, etc.), junto con sus datos fiscales específicos para ese comprobante.

## 📄 Información General
- **ID de Tabla:** `003_PAR`
- **Tipo:** Maestro
- **Reside en:** Disco
- **Longitud del registro:** 22
- **Número de campos:** 7
- **Número de índices:** 3
- **Descripción:** Participantes y roles fiscales dentro de un CFDI.

## 🛠️ Estructura de Campos

| Identificador | Nombre | Tipo | Longitud | Tipo de enlace |
| :--- | :--- | :--- | :--- | :--- |
| `ID` | Código | Numérico | 3 | |
| `CFDI` | CFDI | Numérico | 3 | Maestro: 003_CFDI@datta_erp_dat |
| `ENT` | Entidad | Numérico | 3 | Maestro: 001_ENT@datta_erp_dat |
| `ROL` | Rol | Alfa 256 | 1 | |
| `REG_FIS` | Regimen Fiscal | Alfa 256 | 3 | |
| `USO_CFDI` | Uso de CFDI | Alfa 256 | 3 | |
| `CP_PAR` | Codigo Postal | Alfa 256 | 5 | |

## 🔍 Índices

| Identificador | Nombre | Tipo de indice |
| :--- | :--- | :--- |
| `ID` | Código | Clave única |
| `CFDI` | CFDI | Acepta repetidas |
| `ENT` | Entidad | Acepta repetidas |

## 📝 Notas
- El campo `ROL` define si la entidad actúa como Emisor (E) o Receptor (R).
- Permite capturar el `REG_FIS` (Régimen Fiscal) y `CP_PAR` (Código Postal) vigentes al momento de la emisión, independientemente de los cambios en la tabla maestra de entidades.
