## 📝 Descripción
Catálogo de Estilos Visuales (Temas). Esta tabla permite la personalización estética del ERP a bajo nivel mediante la inyección de hojas de estilo (CSS/QSS). Cada registro contiene un diseño completo (ej. "Dark Mode", "Azure Style") que transforma radicalmente la apariencia de formularios, rejillas y controles, permitiendo que el usuario elija su preferencia visual sin afectar la lógica de negocio.

## 📌 Notas
El campo `CSS` de tipo `Objeto Texto` es ideal para almacenar estilos extensos con variables dinámicas. Esta tabla es consultada directamente por la tabla de configuración global (`004_APP_CFG_W`). Se recomienda validar que el código CSS sea sintácticamente correcto antes de guardarlo para evitar que la interfaz del ERP se corrompa visualmente.
