# Tabla: USUARIOS (USUAR)

Gestión de credenciales y acceso al sistema.

## 📄 Información General
- **ID de Tabla:** `USUAR`
- **Tipo:** Maestra con clave numérica

## 🛠️ Estructura de Campos

| ID | Nombre | Tipo | Longitud | Descripción / Notas |
| :--- | :--- | :--- | :--- | :--- |
| `ID` | ID | Numérico | 10 | Clave primaria. |
| `ENTIDAD` | Entidad | Puntero a Maestro | | Vincula a **Entidades** (Datos de la persona). |
| `LOGIN` | Usuario | Alfabeto | 50 | ID de inicio de sesión. |
| `PASSWORD` | Contraseña | Alfabeto | 128 | Hash de seguridad. |
| `PERFIL` | Perfil | Puntero a Maestro | | Vincula a **Perfiles (Grupos)**. |
| `ACTIVO` | Booleano | Booleano | 1 | |

## 🔍 Índices
- **ID:** Clave única (ID)
- **LOGIN:** Clave única (LOGIN)
- **ENTIDAD:** Clave única (ENTIDAD) - Solo un usuario por entidad.
