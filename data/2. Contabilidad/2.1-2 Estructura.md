# Tabla: CUENTAS CONTABLES (CTAS)

Catálogo de cuentas en estructura de árbol.

## 📄 Información General
- **ID de Tabla:** `CTAS`
- **Tipo:** Maestra con clave numérica
- **Descripción:** Árbol contable jerárquico.

## 🛠️ Estructura de Campos
| ID | Nombre | Tipo | Longitud | Descripción / Notas |
| :--- | :--- | :--- | :--- | :--- |
| `ID` | ID | Numérico | 10 | |
| `PADRE` | Cuenta Padre | Puntero a Maestro | | Apunta a esta misma tabla (Navegación jerárquica). |
| `CODIGO` | Código Cuenta | Alfabeto | 50 | Ej. 101.01.001. |
| `NOMBRE` | Nombre Cuenta | Alfabeto | 256 | |
| `NATURALEZA` | Naturaleza | Alfabeto | 1 | D: Deudora, A: Acreedora. |
| `TIPO` | Tipo Cuenta | Alfabeto | 1 | A: Agrupadora, D: Detalle (Acepta Movimientos). |
| `NIVEL` | Nivel | Numérico | 2 | |
