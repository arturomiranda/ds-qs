# Tabla: SALDOS (SALDO)

Acumuladores automáticos por cuenta y periodo.

## 📄 Información General
- **ID de Tabla:** `SALDO`
- **Tipo:** Maestra con clave numérica

## 🛠️ Estructura de Campos
| ID | Nombre | Tipo | Longitud | Descripción / Notas |
| :--- | :--- | :--- | :--- | :--- |
| `ID` | ID | Numérico | 10 | |
| `CUENTA` | Cuenta | Puntero a Maestro | | Vincula a **Cuentas Contables**. |
| `EJERCICIO` | Ejercicio | Puntero a Maestro | | Vincula a **Ejercicios Fiscales**. |
| `MES` | Mes | Numérico | 2 | |
| `SALDO_INI` | S. Inicial | Numérico | 14 | |
| `DEBE_MES` | Debe Mes | Numérico | 14 | **Actualización desde ASIEN**. |
| `HABER_MES` | Haber Mes | Numérico | 14 | **Actualización desde ASIEN**. |
| `SALDO_FIN` | S. Final | Numérico | 14 | Fórmula: SI + Debe - Haber. |

## 🚀 Notas de Motor (Velneo)
- La inserción/modificación/baja de un **ASIENTO** dispara una actualización automática al **SALDO** correspondiente mediante un Tubo de Actualización.
