# Tabla: ID: 001_PRM
# Nombre: 001: Permisos

## 📄 Información General
- Tipo de tabla: Maestro
- Reside en: Disco
- Longitud del registro: 83
- Número de campos: 16
- Número de índices: 3

## 📝 Descripción
Esta es la tabla de control granular de privilegios. Define de forma binaria (Ver, Agregar, Editar, Eliminar, Cancelar) las acciones permitidas para un Grupo de Usuarios sobre objetos específicos del sistema (Opciones de menú, Tablas o Listas). Es el motor que alimenta la interfaz dinámica; si un usuario no tiene permiso "VER" en una tabla, la opción de menú correspondiente no será visible.

## 📌 Notas
El índice `GRP_TIP_OBJ` es la clave lógica del sistema de seguridad; asegura que no haya duplicidad de reglas para el mismo grupo sobre el mismo objeto. Se recomienda manejar esta tabla mediante un formulario de matriz de permisos para facilitar la administración. Los cambios aquí requieren un refresco de la sesión del usuario para surtir efecto en la interfaz.
