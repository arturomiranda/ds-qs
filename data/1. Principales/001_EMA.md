## 📝 Descripción
Repositorio especializado en la gestión de direcciones de correo electrónico para las Entidades. Esta tabla permite una relación de uno-a-muchos, donde una misma entidad puede tener múltiples cuentas de correo categorizadas para distintos fines (facturación, cobranza, avisos de sistema). Es vital para el motor de notificaciones automáticas y para el envío masivo de comprobantes fiscales electrónicos.

## 📌 Notas
El uso de índices de tipo "Palabras" (`PLB_EMA_BUS`) y "Trozos" (`TRZ_EMA_BUS`) es una decisión arquitectónica orientada a la usabilidad, permitiendo a los usuarios localizar entidades escribiendo solo una parte del correo o el dominio (ej. buscar "gmail" devolverá todas las entidades vinculadas a cuentas de ese dominio). Se recomienda validar el formato del correo mediante expresiones regulares en la capa de aplicación antes del guardado.
