## 📄 Información General

## 📝 Descripción
Esta es la tabla maestra fundamental para la arquitectura Multi-Tenant del sistema. Define la estructura de las Empresas y Sucursales que operan en el ERP. Funciona como el pivote principal de visibilidad; todos los datos transaccionales (Contabilidad, CFDI, Nómina) están filtrados por el ID de esta tabla, garantizando el aislamiento de información entre diferentes razones sociales o unidades de negocio del mismo grupo.

## 📌 Notas
La tabla de Empresas es el "corazón" del sistema. Se recomienda que la aplicación mantenga una variable global (`$G_EMP_ACTUAL`) para inyectar automáticamente este enlace en cada nueva ficha creada en cualquier otro módulo. El campo `CONF_SIS` es una extensión flexible que permite guardar configuraciones particulares sin alterar el esquema físico de la tabla.
