# Tabla: 001: Correos

Esta tabla almacena las direcciones de correo electrónico vinculadas a las entidades.

## 📄 Información General
- **ID de Tabla:** `001_EMA`
- **Tipo:** Maestro
- **Reside en:** Disco
- **Longitud del registro:** 107
- **Número de campos:** 3
- **Número de índices:** 4
- **Descripción:** Repositorio de correos electrónicos asociados a entidades.

## 🛠️ Estructura de Campos

| Identificador | Nombre | Tipo | Longitud | Tipo de enlace |
| :--- | :--- | :--- | :--- | :--- |
| `ID` | Código | Numérico | 3 | |
| `ENT_EMA` | Entidad | Numérico | 3 | Maestro: 001_ENT@datta_erp_dat |
| `DIR_EMA` | Correo Electronico | Alfa 256 | 100 | |

## 🔍 Índices

| Identificador | Nombre | Tipo de indice |
| :--- | :--- | :--- |
| `ID` | Código | Clave única |
| `REL_ENT_EMA` | Por Entidad | Acepta repetidas |
| `PLB_EMA_BUS` | Busqueda Por Palabras Mail | Palabras |
| `TRZ_EMA_BUS` | Busqueda Por Trozos Mail | Trozos de palabras |

## 📝 Notas
- Permite la búsqueda fonética o parcial mediante los índices de palabras y trozos.
- Una entidad puede tener múltiples correos asociados.
