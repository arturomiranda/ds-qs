# Tabla: 002: Asientos

Esta tabla contiene los movimientos individuales de las pólizas contables. Cada asiento representa un cargo o un abono a una cuenta contable.

## 📄 Información General
- **ID de Tabla:** `002_ASI`
- **Tipo:** Maestro
- **Reside en:** Disco
- **Longitud del registro:** 340
- **Número de campos:** 9
- **Número de índices:** 4
- **Descripción:** Registro detallado de movimientos contables (partida doble).

## 🛠️ Estructura de Campos

| Identificador | Nombre | Tipo | Longitud | Tipo de enlace |
| :--- | :--- | :--- | :--- | :--- |
| `ID` | Código | Numérico | 3 | |
| `POL` | Poliza | Numérico | 3 | Maestro: 002_POL@datta_erp_dat |
| `CTA_CNT` | Cuenta Contable | Numérico | 3 | Maestro: 002_CTA_CNT@datta_erp_dat |
| `ENT` | Entidad | Numérico | 3 | Maestro: 001_ENT@datta_erp_dat |
| `NUM_DEB` | Debe | Numérico | 10 | |
| `NUM_HAB` | Haber | Numérico | 10 | |
| `GLO_DET` | Glosa Particular | Alfa 256 | 254 | |
| `CCO_ASI` | Centro de Costo | Numérico | 3 | Maestro: 002_CCO@datta_erp_dat |
| `REF` | Referencia | Alfa 256 | 50 | |

## 🔍 Índices

| Identificador | Nombre | Tipo de indice |
| :--- | :--- | :--- |
| `ID` | Código | Clave única |
| `POL` | Por Poliza | Acepta repetidas |
| `CTA_CON` | Por cuenta | Acepta repetidas |
| `ENT` | Por Entidad | Acepta repetidas |

## 📝 Notas
- El principio de partida doble exige que la suma de los campos `NUM_DEB` coincida con la de `NUM_HAB` dentro de una misma póliza.
- Cada asiento puede vincularse opcionalmente a un `CCO_ASI` (Centro de Costo) para análisis financiero.
- El campo `GLO_DET` permite especificar el motivo particular del movimiento.
