# Tabla: 002: Presupuestos

Esta tabla almacena las proyecciones presupuestales por cuenta contable, ejercicio y mes. Permite el control comparativo entre lo presupuestado y lo realmente ejercido.

## 📄 Información General
- **ID de Tabla:** `002_PRE`
- **Tipo:** Maestro
- **Reside en:** Disco
- **Longitud del registro:** 32
- **Número de campos:** 6
- **Número de índices:** 1
- **Descripción:** Control presupuestal mensual por cuenta contable.

## 🛠️ Estructura de Campos

| Identificador | Nombre | Tipo | Longitud | Tipo de enlace |
| :--- | :--- | :--- | :--- | :--- |
| `ID` | Código | Numérico | 3 | |
| `CTA_CNT` | Cuenta Cont. | Numérico | 3 | Maestro: 002_CTA_CNT@datta_erp_dat |
| `EJE_FIS` | Ejercicio | Numérico | 3 | Maestro: 001_EJE_FIS@datta_erp_dat |
| `NUM_MES` | Mes | Numérico | 2 | |
| `IMP_PRE` | Importe Presup. | Numérico | 10 | |
| `IMP_EJER` | Importe Ejercido | Numérico | 10 | |

## 🔍 Índices

| Identificador | Nombre | Tipo de indice |
| :--- | :--- | :--- |
| `ID` | Código | Clave única |

## 📝 Notas
- El campo `IMP_EJER` se actualiza automáticamente (o mediante procesos) para reflejar los saldos reales acumulados en el periodo.
- Facilita la generación de reportes de variaciones presupuestales.
