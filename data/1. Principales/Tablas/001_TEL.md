# Tabla: ID: 001_TEL
# Nombre: 001: Telefonos

## 📄 Información General
- Tipo de tabla: Maestro
- Reside en: Disco
- Longitud del registro: 22
- Número de campos: 4
- Número de índices: 4

## 📝 Descripción
Repositorio centralizado para la gestión de números telefónicos. Permite vincular múltiples canales de comunicación (Fijo, Móvil, Fax) a las Entidades (`001_ENT`). Es una tabla de apoyo para los módulos de CRM y Atención a Clientes, permitiendo la localización rápida de contactos mediante índices de búsqueda avanzada.

## 🛠️ Estructura de Campos

| Identificador | Nombre | Tipo | Longitud | Tipo de enlace | Comentarios y Relaciones |
| :--- | :--- | :--- | :--- | :--- | :--- |
| `ID` | Código | Numérico | 3 | | ID único del teléfono. |
| `ENT` | Entidad | Numérico | 3 | Maestro: `001_ENT@datta_erp_dat` | Enlace a la entidad propietaria del número. |
| `NUM` | Numero Telefonico | Alfa 256 | 14 | | Número completo, incluyendo ladas o extensiones. |
| `TIP` | Tipo de Telefono | Alfa 256 | 1 | | Clasificación (M: Móvil, F: Fijo, T: Trabajo). |

## 📌 Notas
Se ha simplificado la nomenclatura de los campos (`ENT`, `NUM`, `TIP`) para alinearse con el estándar moderno del esquema. El uso de índices de palabras y trozos permite localizar una entidad incluso si solo se conoce una parte del número telefónico. Se recomienda implementar máscaras de entrada en la UI para normalizar la captura (ej. +52...).
