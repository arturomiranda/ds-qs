# Tabla: 004_TEM: Temas

Esta tabla almacena los diferentes temas (hojas de estilo CSS) que se pueden aplicar a la interfaz de la aplicación, permitiendo centralizar el diseño.

## 📄 Información General
- **ID de Tabla:** `004_TEM`
- **Tipo:** Maestro
- **Reside en:** Disco
- **Longitud del registro:** 84
- **Número de campos:** 3
- **Número de índices:** 4
- **Descripción:** Temas

## 🛠️ Estructura de Campos

| Identificador | Nombre | Tipo | Longitud | Tipo de enlace |
| :--- | :--- | :--- | :--- | :--- |
| `ID` | Etiqueta | Alfa 256 | 40 | |
| `NAME` | Nombre | Alfa 128 | 35 | |
| `CSS` | CSS | Objeto Texto | 8 | |

## 🔍 Índices

| Identificador | Nombre | Tipo de indice |
| :--- | :--- | :--- |
| `ID` | Código | Clave única |
| `NAME` | Alfabético | Acepta repetidas |
| `WORDS` | Palabras | Palabras |
| `PARTS` | Trozos de palabras | Trozos de palabras |

## 🔗 Enlaces Plurales

| Identificador | Nombre | Tabla enlazada | Índice |

## 📝 Notas
- El campo `ID` debe ser descriptivo (Ej: `VAPP-CLARO`, `VAPP-OSCURO`).
- El campo `CSS` almacena el código CSS completo que será inyectado por el proceso `AUTOEXEC` al arrancar la aplicación.
