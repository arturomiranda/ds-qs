# Tabla: ENTIDADES (ENTID)

Esta es la tabla maestra central del sistema. Contiene todos los datos comunes para personas físicas, morales, proveedores, empleados, empresas y usuarios.

## 📄 Información General
- **ID de Tabla:** `ENTID`
- **Tipo:** Maestra con clave numérica
- **Descripción:** Repositorio central de identidades legales y operativas.

## 🛠️ Estructura de Campos

| ID | Nombre | Tipo | Longitud | Descripción / Notas |
| :--- | :--- | :--- | :--- | :--- |
| `ID` | ID | Numérico | 10 | Clave primaria autoincremental. |
| `TIPO_PERS` | Tipo Persona | Alfabeto | 1 | F: Física, M: Moral. |
| `RAZON_SOCIAL` | Razón Social | Alfabeto | 256 | Nombre legal / Apellidos y Nombres. |
| `NOMBRE_COM` | Nombre Comercial | Alfabeto | 256 | |
| `RFC` | RFC | Alfabeto | 15 | Identificador fiscal (NIF/CIF). |
| `CURP` | CURP | Alfabeto | 18 | Para personas físicas (México). |
| `REGIMEN_FIS` | Régimen Fiscal | Puntero a Maestro | | Relación con catálogo de regímenes. |
| `LOGO` | Logotipo / Foto | Objeto Dibujo | | Imagen integrada (Regla: campos integrados). |
| `UUID` | UUID Sincronización | Alfabeto | 36 | Para integración externa (Node.js/IA). |
| `FECHA_ALTA` | Fecha de Alta | Fecha | | |
| `ACTIVO` | Booleano | Booleano | 1 | |

### Categorización (Booleanos)

| `ES_CLIENTE` | Es Cliente | |

## 🔍 Índices
- **ID:** Clave única (ID)
- **RFC:** Clave única (RFC)
- **RAZON_SOCIAL:** Palabras (RAZON_SOCIAL)
- **UUID:** Clave única (UUID)

## 🚀 Notas Velneo 37
- Al ser una tabla maestra con clave numérica, todas las relaciones desde otras tablas (Pólizas, Facturas) usarán un **Puntero a Maestro** apuntando al `ID` de esta tabla.
