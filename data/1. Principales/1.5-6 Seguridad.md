# Tabla: PERFILES (PERFI)

Define los grupos de usuarios y roles en el sistema.

## 📄 Información General
- **ID de Tabla:** `PERFI`
- **Tipo:** Maestra con clave numérica

## 🛠️ Estructura de Campos
| ID | Nombre | Tipo | Longitud |
| :--- | :--- | :--- | :--- |
| `ID` | ID | Numérico | 10 |
| `NOMBRE` | Nombre del Perfil | Alfabeto | 100 |
| `DESCRIPCION` | Descripción | Objeto Texto | |

# Tabla: PERMISOS (PERMI)

Control de acceso granular a objetos y procesos.

## 📄 Información General
- **ID de Tabla:** `PERMI`
- **Tipo:** Maestra con clave numérica

## 🛠️ Estructura de Campos
| ID | Nombre | Tipo | Longitud | Descripción |
| :--- | :--- | :--- | :--- | :--- |
| `ID` | ID | Numérico | 10 | |
| `PERFIL` | Perfil | Puntero a Maestro | | Vincula a **Perfiles**. |
| `OBJETO_ID` | ID del Objeto | Alfabeto | 100 | ID del objeto en Velneo. |
| `ACCESO` | Nivel Acceso | Alfabeto | 1 | L: Lectura, E: Escritura, T: Total, N: Ninguno. |
