# Tabla: COMPLEMENTOS (COMPL)

Datos adicionales del CFDI (Nómina, Pagos, etc).

## 📄 Información General
- **ID de Tabla:** `COMPL`
- **Tipo:** Maestra con clave numérica

## 🛠️ Estructura de Campos
| ID | Nombre | Tipo | Longitud | Descripción |
| :--- | :--- | :--- | :--- | :--- |
| `ID` | ID | Numérico | 10 | |
| `COMPROBANTE` | Comprobante | Puntero a Maestro | | Vincula a **Comprobantes**. |
| `TIPO_COMPL` | Tipo Complemento | Alfabeto | 50 | Nómina, Pago, CP, etc. |
| `JSON_DATA` | Datos Complemento | Objeto Texto | | Estructura JSON con los campos específicos del complemento. |

# Tabla: EMISORES / RECEPTORES (PARTI)

Participantes del comprobante vinculados al catálogo central.

## 📄 Información General
- **ID de Tabla:** `PARTI`
- **Tipo:** Maestra con clave numérica

## 🛠️ Estructura de Campos
| ID | Nombre | Tipo | Longitud | Descripción |
| :--- | :--- | :--- | :--- | :--- |
| `ID` | ID | Numérico | 10 | |
| `COMPROBANTE` | Comprobante | Puntero a Maestro | | Vincula a **Comprobantes**. |
| `ENTIDAD` | Entidad | Puntero a Maestro | | Vincula a la tabla **Entidades** (Master). |
| `ROL` | Rol | Alfabeto | 1 | E: Emisor, R: Receptor. |
| `REGIMEN_FIS` | Régimen Fiscal | Alfabeto | 3 | Copia del régimen al momento de emisión. |
| `CP_USO` | CP / Uso CFDI | Alfabeto | 10 | |
