# Tabla: 001: Tipos de Cambios

Esta tabla almacena los valores históricos de las tasas de cambio para las diferentes monedas.

## 📄 Información General
- **ID de Tabla:** `001_TDC`
- **Tipo:** Maestro
- **Reside en:** Disco
- **Longitud del registro:** 20
- **Número de campos:** 4
- **Número de índices:** 2
- **Descripción:** Registro histórico de tipos de cambio por moneda y fecha.

## 🛠️ Estructura de Campos

| Identificador | Nombre | Tipo | Longitud | Tipo de enlace |
| :--- | :--- | :--- | :--- | :--- |
| `ID` | Código | Numérico | 3 | |
| `MON_TDC` | Monedas TDC | Numérico | 3 | Maestro: 001_MON@datta_erp_dat |
| `FEC_VAL` | Fecha Valida | Fecha | 3 | |
| `VAL` | Valor | Numérico | 10 | |

## 🔍 Índices

| Identificador | Nombre | Tipo de indice |
| :--- | :--- | :--- |
| `ID` | Código | Clave única |
| `MON_FEC` | Monedas Fecha | Clave única |

## 📝 Notas
- El campo `VAL` almacena la paridad de la moneda respecto a la moneda base del sistema (generalmente MXN).
- El índice `MON_FEC` asegura que solo exista un tipo de cambio por moneda para una fecha específica.
