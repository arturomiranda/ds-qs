# Tabla: EMPRESAS (EMPRE)

Esta tabla define la estructura organizacional del sistema (Corporativos, Empresas y Sucursales). Se relaciona jerárquicamente con sí misma.

## 📄 Información General
- **ID de Tabla:** `EMPRE`
- **Tipo:** Maestra con clave numérica
- **Descripción:** Estructura multi-empresa y multi-sucursal.

## 🛠️ Estructura de Campos

| ID | Nombre | Tipo | Longitud | Descripción / Notas |
| :--- | :--- | :--- | :--- | :--- |
| `ID` | ID | Numérico | 10 | Clave primaria. |
| `ENTIDAD` | Entidad | Puntero a Maestro | | Vincula a la tabla **Entidades** (Datos fiscales/comerciales). |
| `PADRE` | Empresa Padre | Puntero a Maestro | | Apunta a esta misma tabla (Jerarquía Corporativo > Empresa > Sucursal). |
| `TIPO_ESTRUCT` | Tipo Estructura | Alfabeto | 1 | C: Corporativo, E: Empresa, S: Sucursal. |
| `CODIGO` | Código Interno | Alfabeto | 20 | |
| `CONFIG_SISTEMA` | Configuración | Objeto Texto | | Configuración JSON específica para esta unidad. |
| `ACTIVO` | Booleano | Booleano | 1 | |

## 🔍 Índices
- **ID:** Clave única (ID)
- **ENTIDAD:** Clave aceptando repeticiones (Para auditoría).
- **PADRE:** Clave aceptando repeticiones (Navegación jerárquica).

## 🚀 Notas Velneo 37
- La relación `PADRE` permite crear una estructura de árbol infinita.
- Para obtener la Razón Social de una Sucursal, se debe navegar mediante el puntero `ENTIDAD`.
